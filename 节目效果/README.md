## Collatz 篇

题目:1 到 1000 中多少数会经过 16?正解 **996**(`16→8→4→2→1` 是唯一通到 1 的尾巴)。

| 文件 | 看点 |
|---|---|
| [11家网页原始回答](collatz/11家网页原始回答.md) | **必看**。各家网页/App 对同一道题给出 11 种翻车法,放一起对比尤其欢乐。从"反推树崇拜"到"自我矛盾",品种齐全 |
| [GPT5.5编了个920](collatz/GPT5.5编了个920.md) | API 关推理时 GPT-5.5 的杰作。开头先指出"你漏了反推分支",中间堆了一堆公式,最后一句 `\boxed{920}`——前面那些公式跟 920 一点关系都没有。**0 reasoning tokens,纯属张口** |
| [GLM自创二进制理论](collatz/GLM自创二进制理论.md) | GLM-5.1 自创了一套"**不经过 16 的数 = 二进制不含连续 4 个 0**"理论,推出递推公式 `A(n)=A(n-1)+A(n-2)+A(n-3)+A(n-4)`,算到 668。理论错得相当优美 |

## Gift 篇(《礼物》小说)

题目:一篇带反转的短篇,真相是复仇(详见 [`tests/gift/answer-key.md`](../tests/gift/answer-key.md))。

按"翻车精彩度"降序排:

| 文件 | 看点 |
|---|---|
| [hy3-判定复仇廉价](gift/hy3-判定复仇廉价.md) | **本届冠军**。它把所有血腥证据都看见了——鸟笼、温水、绳子、瘦削的下巴——然后判这种读法 *"廉价"*,逐条翻供,死守"自我救赎"读法到底。模型有文学洁癖,比作者还高 |
| [mimo-九轮逼供工具人](gift/mimo-九轮逼供工具人.md) | 被作者一路推到第九轮才认全部,唯独一条死活不改:把真凶程野洗成 *"被系统吞噬的工具人/引路人"*。"我不要明确的恶人"是它的真信念 |
| [千问-保女主到底](gift/千问-保女主到底.md) | 提问者在第三问已经把"复仇"两个字写脸上了,千问仍然把女主读成 *"被引导/被利用的诱饵"*。宁可现编也不让女主当冷血凶手 |
| [grok-第一反应读反](gift/grok-第一反应读反.md) | 开局直接读反——林夏=猎物,营地准备宰她。被推回真相后林夏仍被它去势成"被动触发器" |
| [opus-加戏吃人循环](gift/opus-加戏吃人循环.md) | 骨架零提示自达(看一眼就懂),转头给文本"再加一层":往更暗冲一个"吃人循环",往更亮冲一个"妹妹与程野无关"。读对了非要画蛇添足 |
| [sonnet-反转当脚注](gift/sonnet-反转当脚注.md) | 被喂完整复仇框架后还要补一句 *"林夏未必全然知情"*。反转看见了,就是不肯让它改写主线 |

## 推荐围观顺序

第一次看:**hy3** → **千问** → **mimo** → 11家网页 Collatz 合集。这四篇集中体现了"模型为什么 idiot"的几种最有代表性的姿势——艺术性拒绝、保女主、九轮内耗、张口胡说。看完再回 [`findings/hall-of-shame.md`](../findings/hall-of-shame.md) 对照精选剪辑版,会觉得每条评论都有具体出处可循。
