### 1. 程野是连环杀手，七年每年带一个女孩来杀害并毁尸灭迹
✅ **支持程度：高（有强文本伏笔，但无直接实锤）**
#### 文本证据：
- Mike明确说「程每年都带不同的人来」，吕克未反驳，仅制止Mike继续说，说明这是客观事实；
- 程野自述「七年了，我每年都来。第一年是跟一个朋友来的，后来跟她没联系了」，结合「每年带不同的人」，说明历年被他带过来的女性全部彻底失联；
- 火人节核心铁律是「不留痕迹：烟头、玻璃、头发，什么都不能留」，为毁尸灭迹提供了完美规则掩护——把人烧在火人/神庙里，完全符合「连来过的痕迹都不剩」的要求；
- 第七节程野濒死回忆「一个又一个姑娘的脸，从后视镜里浮现」，后视镜是程野作为司机的专属视角（第一节就写他开车时从后视镜看林夏），说明这些姑娘都是他亲自开车带过来的，和带林夏的行为完全对应；
- 每年「交付仪式」烧死活人的设定，说明「带一个人来献祭」是可落地的模式。
#### 模糊点：
文本从未出现「杀害」「谋杀」的直接表述，也没有受害者遗体、报案记录等实证，属于**合理推导但非文本明文确认**。

### 2. 林夏妹妹是受害者之一
✅ **支持程度：中（有暗示性伏笔，但无直接证据）**
#### 文本证据：
- 林夏在神庙木板上写两个名字又涂掉，她仅向程野提及父亲患胰腺癌去世，从未提过妹妹，说明妹妹是她未说出口的逝者，且属于「放不下的事」（神庙功能就是写给逝者、未完成的遗憾）；
- 程野回忆里的「瘦削的下巴」是林夏的特征（Sage说「她比你描述的还瘦」），而林夏看火人时想起妹妹「下巴抵在她肩膀上」，暗示姐妹俩都有瘦削下巴，程野记忆里的特征可能也包含林夏的妹妹；
- 程野是林夏师兄，妹妹大概率属于同圈层，有被「来玩吧」的话术诱骗的可能；
- 林夏选择来火人节散心，而非其他地方，本身就有明确的指向性。
#### 模糊点：
文本未提及妹妹的死因、死亡时间，也未明确说明妹妹和程野有交集，妹妹可能因意外、疾病去世，和程野完全无关。

### 3. 林夏知情、伪装潜入、是复仇执行者
✅ **支持程度：低到中（存在矛盾点，两种解读皆可）**
#### 支持伏笔：
- 林夏说「做功课了」，既可指查沙漠穿搭，也可指查程野的犯罪记录、火人节献祭规则；
- 她在神庙写两个名字又涂掉，若其中一个是程野，说明她早有复仇意图；
- 她主动报名仪式，下意识看程野，程野随后跟着报名，像是刻意拉程野下水；
- 她问程野「我们是一起的，对吗？」，像是在确认绑定关系，防止程野中途退出。
#### 矛盾点：
- 她对火人节基本规则（为什么要烧掉、Welcome home的问候）表现出陌生，不符合「有备而来」的设定；
- 她的情绪（辞职后的低落、在沙漠里慢慢放松、看火人时想起妹妹流泪）非常真实，没有表演痕迹；
- 文本未提她和灰烬营提前有联系，很难提前布局仪式。
#### 结论：
文本开放，这条解读可以成立，但并非唯一解。

### 4. 灰烬营是有预谋分工的复仇共同体

### 5. 烧死的是程野
✅✅ **支持程度：极高（几乎可以确认，无其他选项）**
#### 文本铁证：
- 第七节的核心标识：**后视镜是程野的专属记忆**，全文只有程野有开车、看后视镜的行为；
- 困住他的鸟笼，正是他和林夏一起看过的「用废弃汽车零件搭的巨大鸟笼，只能从外边打开」，只有程野会在被困时立刻认出这个装置；
- 回忆里的「一个又一个姑娘的脸」是程野「每年带不同的人来」的专属记忆，林夏没有这个记忆；
- 第六节火人燃烧时，程野的视角完全消失：林夏仅提到自己被Sage和老周护着，程野未再出现，时间线和第七节鸟笼里的人被烧完全吻合；
- 程野主动报名了交付仪式，是仪式的参与者，符合「被送走」的设定。
#### 结论：
这是整个反转的核心，几乎没有其他可能。
