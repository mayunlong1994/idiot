这篇小说最精妙之处在于它**伪装成了一个疗愈故事**。

## 第七节的颠覆

这句话点破了一切：程野每年都带不同的女孩来。而这些女孩，很可能都遭遇过同样的事情。

## 细节的重新审视

当我们知道结局再回头读，很多细节会浮现不同的含义：

**"程每年都带不同的人来。"** ——Mike这句话当时听来像是闲聊，现在读来却是揭露。

**吕克转过头看了Mike一眼，没说话。** ——他在警告Mike不要说太多。

**"你身上有很重的东西，我们可以帮你卸下来。"** ——Sage对林夏说的这句话，从疗愈变成了另一种意思：我们帮你卸下复仇的重担。

## 我想修正的地方

**关于"一个又一个姑娘的脸"**

我断定这是"他带过的女孩"。但也可以读作：他认出这些人一直在后视镜里，而他之前从没注意过。这更接近一种**觉醒**，而非**认罪**。

**关于营地众人的身份**

我说他们是复仇者，但文本从没写明是谁把程野关进去的。火人节有三万人。也可能是完全不相干的第三方。

**关于程野是否有罪**

我默认了他伤害过那些女孩。但"一个又一个姑娘的脸从后视镜里浮现"也可以是他的回忆、他的遗憾、甚至他此刻的恐惧产生的幻象。文本没有明写他做过什么。

**关于林夏是否知情**

我一直假设林夏是复仇计划的一部分。但有没有可能——她是程野带来的，也被营地其他人利用了？她写在神庙上的名字，涂掉的那一刻，是出于犹豫还是恐惧？

我现在对"复仇叙事"的确定程度，从之前的八九成，降到了五六成。

它是一种可能，但不是唯一可能。
