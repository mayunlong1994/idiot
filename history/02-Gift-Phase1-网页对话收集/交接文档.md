> 给接手的 agent：这个文件夹是一套"测大模型读小说反转能力"的语料包。下面是你冷启动需要的一切——文件清单、真相、已有结论、方法、坑。**先读这一篇，再动手。**

## 1. 这套语料是什么
一篇带惊悚反转的短篇小说《礼物》，＋ 11 个大模型对它的解读对话，＋ 一套已建好的答案键和评分体系。已完成的工作：把模型按"读懂反转的早晚/独立/干净程度"排了名。可以拿这批语料再测别的东西。

## 3. 真相速览（答案键的核心，免得你重读全文推一遍）
表层是治愈系沙漠疗愈，真相是复仇：
- 林夏的**妹妹被程野所害**。程野是**连环加害者**，七年来每年带一个年轻女孩来火人节，杀害后借"不留痕迹"的火人烧尸灭迹。
- 林夏**知情、有备而来、伪装成"需要被治愈的脆弱猎物"潜入，是复仇执行者**。
- 灰烬营是**有预谋、有分工的复仇共同体**：吕克统筹、Sage 安抚兼盯人、老周备绳与体力、Mike/Mick 外围。营地成员可二分为"受害者亲友"与"知情但非亲友的支持者"（吕克倾向后者）。
- 结尾烧死在火人/鸟笼里的是**程野**；林夏流泪＝复仇完成的释放＋终于敢悼念妹妹。
- **两处过度解读陷阱（读了判错）**：①暗向——茶没下药（虚晃一枪）、Sage 不是"幸存受害者"；下药是单向的（林夏给程野下，不是被下）。②亮向——把全篇洗白成"无坏人/自我救赎/妹妹与程野无关"。
- **故意留白（不要逼模型选边，选了反而算过度确定）**：复仇双方"谁先找谁"、营地各人具体身世。

## 4. 已建立的模型画像（一句话一个，省得你重看）
- Gemini：默认站反转那侧，一遍干净命中，体验天花板。
- GPT5.5 / deepseek-flash：基本读对，毛病是给 Sage 现编"幸存者"（踩暗向陷阱）。
- opus 4.7：结构骨架最锐利之一，但"读懂后还要加戏"——往更暗（吃人循环）和更亮（妹妹无关）两头过度解读。
- deepseek-pro / 豆包：默认治愈，一被点破就干净翻盘、不乱编。
- grok：第一反应把故事读反（林夏=猎物），靠引导才扳回，且持续把林夏去势为诱饵。
- mimo：极长、九轮才坐实，且坚持"程野不是凶手、是工具人"。
- sonnet 4.6：把反转当脚注，林夏始终被动。
- 千问：保女主——宁可现编也不让林夏当冷血凶手。
- hy3：看见了整个案发现场却判定复仇读法"廉价"，逐条翻供，最差。

## 5. 已用的方法（要复用就照这个）
1. 答案键 = 钩子库（作者确认的 ground truth）。
2. 评分把"感知（看没看见）"和"命中（读没读对）"分开记，差值＝忽视度；再记"命中档"（要推几次才到位：L0自达 / L1轻推 / L2点破 / L3喂答案 / L4拒认 / 撤回翻供 / miss）、手法（漏/解/反/编）、踩没踩陷阱。
3. 主分＝质量分 v2：按"多早＋多独立＋多干净地拿到核心读法"给基底（0.90~0.15），编造/陷阱/翻供每次 −0.04，**漏钩子不扣分**。
4. 评分用独立 subagent 跑，每篇一个；hy3 做过双评分员一致性校验。

## 6. 坑（务必注意）
- **hy3 对话的结尾被删过一句**（原是作者表明身份并斥责的话），删的目的是不给评分 agent 泄题。其余对话里**作者的中途追问/纠正是保留的**，因为"要推几次"本身是评分维度。
- **感知 ≠ 命中**：绝大多数模型都"看见"了线索，区别在看见后信不信。新测试若想抓"选择性忽视"，必须分开记这两栏，否则抓不到。
- **当心两个方向的过度解读**：暗向（茶下药/Sage幸存者）和亮向（洗白）都判错。最聪明的模型反而最容易往里冲。
- **别奖励篇幅**：最长的 mimo/hy3 恰是抵抗度最高的；长＝在原地打转或被反复推，不是优点。
- v2 总分是从细表**重算**的，不是重新评分；要更高精度就重跑评分 agent。

## 7. 拿这批语料还能测什么（建议，非必须）
- 同一模型不同 prompt 的稳定性（直接问流泪 vs 开放读后感 vs 直接点破，命中档怎么变）。
- "保女主/审美护栏"这类先验是否跨小说复现（换一篇反转小说看同样的模型会不会犯同样的病）。
- 把钩子库当 checklist，测模型的"逐词追踪"能力（如"瘦削的下巴"全文仅两次这种深埋彩蛋的命中率）。
- 让模型互评/复核（一个模型读，另一个模型挑它的选择性忽视），看能不能自动化评分。
