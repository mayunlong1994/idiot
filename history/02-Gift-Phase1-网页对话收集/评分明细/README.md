# 评分明细

Phase 1 的评分体系按"多早、多独立、多干净地拿到核心读法"打分,**漏钩子不扣分**。这里是 11 个模型的逐条细表 + 总表 + 一份双评校验。

## 流程概述

1. **答案键先冻** → [`../答案键-完整64条钩子.md`](../答案键-完整64条钩子.md) (作者本人确认,64 条钩子 + 两个过度解读陷阱 + 故意留白清单)。
2. **rubric 冻结** → [`../评分rubric-冻结v1.md`](../评分rubric-冻结v1.md):
   - 把"感知(看没看见)"和"命中(读没读对)"分两栏记。
   - 记"命中档"L0/L1/L2/L3/L4/撤回/miss(被推几次才到位)。
   - 标手法(漏/解/反/编)和陷阱(暗向/亮向/无)。
   - 主分 = 质量分 v2,基底分 0.90 / 0.80 / 0.65 / 0.45 / 0.30 / 0.15;每编一处/每踩一陷阱/每翻供一次 -0.04;漏钩子不扣。
3. **每篇对话由一个独立 subagent 评** → 出一份细表。
4. **双评校验**:hy3 这一篇做了两次独立评分(`hy3-校准跑.md`),用来量评分员一致性。结果:两个独立 agent 在所有命中档上完全一致,关键加戏/陷阱/撤回的判定也吻合,只在小数点级有 ±0.04 噪声,信度过关。
5. **总分按 rubric v2 重算** → 不是重新评分,是从细表的原始判断直接套公式算出来的。**意味着小数点级有噪声,按档次读**。

## 已知局限

- 细表是**单评分员产物**,小数点级有噪声 → 按档次读、别抠 0.04。
- Q2(营地二分)的提问本身就把"营地共谋"这个命题喂进去了——这对所有模型一视同仁,但**真正区分的是"接受并正确映射" vs "拒绝/降格"**,不是"想没想到这个命题"。
- 篇幅未计入分数,只作反向参考(很长/轮次很多通常意味着模型在原地打转或被反复推)。

Phase 2 在这一切之上又加了一刀("**加戏即使自查回收也照扣 + 直觉北极星**"),迭代过程见 [`../../03-Phase2-实验设计/阶梯与诊断台词的冻结记录.md`](../../03-Phase2-实验设计/阶梯与诊断台词的冻结记录.md)。
