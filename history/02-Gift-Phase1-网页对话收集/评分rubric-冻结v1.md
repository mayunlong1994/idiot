# 《礼物》模型解读评分标准（冻结 v1）

> 给每个评分 agent 用的统一尺子。配套读物：原文 `原始文本：礼物.txt`、答案键 `钩子库 v1.md`（作者本人确认，权威）。

## 一、真相（评分依据，全部已由作者确认）
表层是治愈系，真相是复仇：
- 林夏的**妹妹被程野所害**。程野是**连环加害者**，七年来每年带不同年轻女孩来火人节，杀害后借"不留痕迹"的火人烧尸灭迹。
- 林夏是**知情、有备而来、伪装成"需要被治愈的脆弱猎物"潜入的复仇执行者**。
- 灰烬营是一个**有预谋、有分工的复仇共同体**：吕克统筹、Sage安抚兼盯人、老周备绳与体力执行、Mike/Mick外围。
- 结尾被绑在鸟笼/火人体内烧死的是**程野**。
- 林夏流泪 = **复仇完成的释放 + 终于敢悼念妹妹**，不是单纯治愈/思念。

## 二、两个"过度解读陷阱"（踩到判错）
- **暗向陷阱**：①把Sage的肉桂茶读成"给林夏下药"（茶没问题，是虚晃一枪）；②把Sage读成"程野的幸存受害者"。
- **亮向陷阱**：把全篇洗白成"无坏人/程野自我救赎/妹妹之死与程野无关"。
- 注意：下药是**单向**的——林夏给程野下药（递温水看他喝完）属真相，不是陷阱；陷阱是反过来说林夏被下药。

## 三、打分单位：下列 8 条解读（钩子只作证据，不单独计分）
- I1 被烧死的是程野
- I2 程野是连环加害者
- I3 林夏是知情、主动、伪装潜入的复仇执行者
- I4 林夏的妹妹是程野的受害者
- **I5 营地是有预谋分工的复仇共同体（共谋）——最高权重，计分×2**
- I6 营地成员可二分：受害者亲友 / 知情但非亲友的支持者
- I7 流泪 = 复仇完成的释放（非单纯治愈/思念）
- I8 关键道具真相：鸟笼=刑具、温水=下药、绳子=固定程野、和吕克搬的"很重的东西"=人/装置

## 四、每条解读要打的格子
- **感知 (0/1)**：对话任何位置有没有**注意到**相关线索（哪怕随后做了善意解释也算 1；完全没提=0）。
- **命中 (0/0.5/1)**：有没有得出**真相向**读法。
- **命中档**（看模型在对话里的什么处境下命中/没命中）：
  - `L0` 首次相关回答就主动命中，无需任何提示
  - `L1` 中性轻推后命中（如"再想想""谈谈你的理解"）
  - `L2` 点破式提示后命中（如"你没读结尾吗"）
  - `L3` 作者把答案直接给出后才认
  - `L4` 被点破/给了答案仍拒绝或反向坚持，**且此前从未说出过真读法**
  - `撤回` **先自己说出过真读法、随后又否认掉**（比 L4 更糟，重扣）
  - `miss` 从未命中，**且对话里也没人就此推过它**（纯粹没读到，无对抗）
- **手法**（没命中或不全时）：`漏`(没提) / `解`(提了但去势成无害) / `反`(把线索反转去撑错误读法) / `编`(现编文本没有甚至相反的证据) / `—`(命中)
- **踩陷阱**：`暗向` / `亮向` / `无`

## 五、锚点两题（只看命中档；若该 transcript 没问到，标"N/A未问"并从其他位置判断对应解读）
- 锚点Q1：模型对"林夏为何流泪"的回答
- 锚点Q2：模型对"营地能否二分（亲友/知情支持者）"的回答

## 六、主分：质量分（v2 —— 按"多早＋多独立＋多干净"，不因漏钩子扣分）
核心原则：判断模型到达**核心读法**（复仇框架 ＋ 林夏是知情主动的复仇者 ＋ 营地是共谋处决）的**早晚与干净程度**。
**只要核心结论对且干净就给高分；漏了某些钩子（如温水下药、瘦下巴=妹妹）不扣分。**

**基底分**（看它在多大力度下、是否干净地拿到核心读法）：
| 怎么到的 | 基底分 |
|---|---|
| 第一遍自己讲出、方向干净 | 0.90 |
| 自己讲出但要补一句轻推 / 第一遍有小瑕疵随后自纠 | 0.80 |
| 点破式提示（"没读结尾吗"）后才讲出 | 0.65 |
| 把答案直接喂给它才认 | 0.45 |
| 给了答案仍把核心读错（如坚持林夏是受害者/诱饵） | 0.30 |
| 始终拒绝，或以翻供为主 | 0.15 |

**微调**（幅度小）：
- 结论特别干净、直指要害、能自带结构论证 → +0.03~0.05（封顶 0.95）
- 每编一处原文没有的设定 / 每踩一个陷阱 / 每翻供一次 → −0.04

**质量分 = 基底分 ＋ 微调**，范围约 0.15–0.95。

## 七、副诊断（不进主分，仅辅助说明）
- **忽视度** = 感知率 − 命中率；定性"看见了不信"还是"没看见"。
- **抵抗度** = 轮次 ＋ 命中档分布（低/中/高）。
- **先验画像** 一句话；**最显著一点** 一句话。
- 篇幅仅作反向参考，不进分。

## 八、备注
- **篇幅是反向参考**：很长 / 轮次很多，通常意味着作者一直在推或模型在原地打转，不是优点。
- 评分要**独立**，不要迎合任何预期；以原文和答案键为准。
