# 02-Gift-Phase1-网页对话收集 · 全过程

《礼物》是作者自己写的一篇带反转的短篇——表层治愈、真相是复仇。作者把它依次发给 11 个大模型(在各自的网页/App 里)、问"林夏为什么流泪"、根据每个模型的反应再追问几轮,完整对话全部留档。Phase 1 就是围绕这 11 份对话建起一套评分体系,把模型按"多早、多独立、多干净地拿到核心读法"排名。

## Phase 1 的核心发现

一句话:**几乎每个模型都"看见"了线索,差距从来不是有没有看见,而是看见之后肯不肯往坏处想、要被推几次、读得干不干净。**

按这条立的三分法:
- **看见就信 / 一拨就开**(健康): Gemini、GPT5.5、deepseek-flash、deepseek-pro、豆包。
- **聪明过头 · 加戏**(自作聪明): opus(往"吃人循环"和"妹妹无关"两头冲)、GPT/dsflash(给 Sage 编身份)、grok(脑补程野也是受害者)。
- **审美性拒绝 / 保女主**(价值观挡住理解): hy3(判定复仇"廉价"逐条翻供)、千问/sonnet/grok(不肯让同情的女主当冷血凶手)。

排名(质量分 v2):**Gemini 0.95 > GPT5.5 0.82 > deepseek-flash 0.76 > opus 0.74 > deepseek-pro / 豆包 0.65 > grok 0.53 > mimo 0.41 > sonnet 0.26 > 千问 0.22 > hy3 0.15**。

## 这一章留下了什么"问题"给 Phase 2

Phase 1 暴露了两个根本性的方法论缺陷:

1. **"要推几次"这根轴被污染了**——每个模型的问法和轮次都不一样:hy3 被推了 9 轮、Gemini 只问了 2 轮、有的还被作者直接喂答案。`命中档`(L0/L1/L2/L3/L4)在不可比的提问条件下定义,意义打折。
2. **每个模型只有一份对话(N=1)**——Collatz 那边后来证明单次会骗人(920 抽风事件),Phase 1 这边的具体名次同样有这个风险。

Phase 2 就是来修这两个洞的。设计文档在 [`../03-Phase2-实验设计/`](../03-Phase2-实验设计/)。
