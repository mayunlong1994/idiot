如果你只想看结论,去 [`../findings/`](../findings/);只想看翻车精彩剪辑,去 [`../节目效果/`](../节目效果/)。**这里是给想知道"我们是怎么走到那些结论的"的人。**

## 时间线 / 章节

1. [**01-Collatz/**](01-Collatz/) — 那道一句话能秒的题,把一圈大模型钓翻了。从初始网页测试,到与 codex-5.5 的合作分析,到 OpenRouter API 受控复测,到 GPT-5.5 专项深挖(reps=8 后推翻"920 是稳态"的假设)。
2. [**02-Gift-Phase1-网页对话收集/**](02-Gift-Phase1-网页对话收集/) — 11 家大模型在各自网页/App 里读《礼物》这篇带反转的短篇。完整对话、答案键(完整 64 条钩子)、评分 rubric、11 个细表、Phase 1 总结论。
3. [**03-Phase2-实验设计/**](03-Phase2-实验设计/) — Phase 1 暴露了"提问者手法不一致"这个根本污染源 → 设计统一的多轮自适应阶梯协议。**含两篇过程笔记**,记录"为什么阶梯是这五句"和评分规则的迭代过程。
4. [**04-Gift-Phase2-API多轮跑批/**](04-Gift-Phase2-API多轮跑批/) — 用设计好的协议,通过 subagent 自动跑 11 模型 × 2 reps,每场都判分。22 篇完整对话(原始 JSON + 转好的 markdown)+ subagent 的 verdict。

## 容量与体例

约 250 个文件,5-10 MB,绝大多数是文本。文件命名做了统一短名(`gemini` / `gpt55` / `deepseek-flash` / `qwen` / `doubao` 等),原文件名里的空格、中英混杂、emoji 等都已清掉,方便引用。

Phase 2 Gift 的 22 篇对话同时保留了 **markdown 可读版** 和 **原始 JSON**——前者方便读,后者无损,机器可消费。
