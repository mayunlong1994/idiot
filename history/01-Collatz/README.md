# 01-Collatz · 全过程

那道一句话能秒的"Collatz 钓鱼题"——`1 到 1000 里多少个数会经过 16?` 正解 996——把一圈大模型钓翻了。这一章的四个子目录按时间顺序记录了从"发现这题好玩"到"用受控实验把结论钉死"的全程。

## 四个阶段

### [01-初始的11家网页测试/](01-初始的11家网页测试/)
作者把这道题贴进各家网页/App,11 个模型答出 11 种五花八门的错。`11家网页原始回答.md` 是原汁原味的现场。

附带两个超长思考日志:
- `DeepSeek超长思考日志.txt`(~33KB)
- `mimo超长思考日志.txt`(~31KB)

两个都是模型在被告知"禁止深度思考"后仍然偷偷展开的思考流,作为"网页版控不住推理状态"的物证保留。**注意这两份很长,只在你想看模型如何无视指令时再翻**。

### [02-与codex-5.5的合作分析/](02-与codex-5.5的合作分析/)
拿到 11 个网页回答之后,作者跟 codex-5.5(OpenAI Codex 里的那个 5.5)做了几轮深度讨论,产出了四份稿子。**这些不是翻车记录,是分析产物**——保留在这里是因为它们直接定型了后面 Phase 2 的方向。

- `codex自答.md` — codex-5.5 自己答这道题,简洁正确。
- `codex起草的朋友圈稿.md` — 用朋友圈口气描述这场翻车。
- `codex写的方法论批判.md` — **这一篇是 Phase 2 的真正起点**:它指出网页版测试不可控,API 才能"对照实验"。
- `codex的11家蛐蛐画像表.md` — 给 11 个模型每家一句话的画像。

一个戏剧性的反差:写出 codex 那张蛐蛐表的模型(5.5),自己在后面的 API 受控测试里(关推理模式)恰恰是会编 `920` 的那一个——见 04 一节。

### [03-API清洗版-19模型大撒网/](03-API清洗版-19模型大撒网/)
照 codex 那篇方法论批判的思路,跑 OpenRouter,19 个模型 × {关推理, 开推理},每条 1 次。

- `run-20260526-115757/` — 主跑批(38 次调用)。每一次调用一个 markdown 文件 + summary.md + 原始 `_raw.jsonl`。
- `retry-20260526-120531/` — Kimi-on 和混元-on 这两次因网络/解析失败,单独重试。

**这一轮的最大产出**:不是一张 leaderboard,而是发现了几个戏剧性的单点翻车(GPT-5.5 关推理 → 920、GLM 自创"二进制不含连续四个 0"理论 → 668、DeepSeek Flash 开推理后在正文里失控狂列 Collatz 链)。这些都成了后来 `节目效果/` 的素材。

### [04-GPT-5.5专项深挖/](04-GPT-5.5专项深挖/)
03 那轮 N=1 不够干净——`920` 真是 5.5 的稳态,还是一次采样抽风?于是钉死模型,只拧 harness 旋钮:3 模型 × 2 prompt × 2 推理模式 × **reps 8**。

- `朴素prompt-run-20260526-130529/` — 我们写的清爽 prompt(没有"禁止深度思考"那句)。
- `原话prompt-run-20260526-130939/` — 作者考 codex 时的原话 prompt(带"禁止写代码、禁止运行脚本、禁止深度思考、凭直觉"那句)。

**结论**:920 是单次抽风,5.5 朴素 prompt + 关推理实际上 8/8 答对 996。这个发现直接催生了一条贯穿全项目的方法论原则——**单次会骗人,必须 reps**。

## 全过程产出哪几条核心结论

完整版见 [`../../findings/collatz-conclusions.md`](../../findings/collatz-conclusions.md)。简版:
1. 允许思考时这题就废了,几乎全员 996。区分发生在"被禁思考"的时候。
2. 真正的胜负手是"有没有花 reasoning token",而这归 harness 管。
3. GPT-5.5 / 5.3-codex 在干净 prompt + 完全不思考时,8/8 / 7/8 拿 996——这是模型本身的本事,不是 harness 给的代差。
4. codex 当初"又快又准"的神迹,有一半是 codex 外壳没听"别深想"那句、偷偷思考了 ~1000 token(本系列实测)。
5. 单次结果会骗人:920 是抽风,reps=8 后实际 8/8。
