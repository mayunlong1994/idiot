# 11 条提问序列分析 —— 用于阶梯设计

> 这是 Phase 2 设计的起点之一。把 Phase 1 里作者对 11 个模型的实际提问序列**逐条抽出来**,平铺在一起对比,**问法不一致这件事直接被坐实**——而这件事正是 Phase 1 命中档不可比的根本原因。

## 数据怎么来的

每篇 Phase 1 对话([`../02-Gift-Phase1-网页对话收集/11家网页对话原文/`](../02-Gift-Phase1-网页对话收集/11家网页对话原文/))里都有"作者问 → 模型答"的交替。让 11 个并发的 subagent 各自读一份对话,**只抽作者那一侧的发言、按顺序编号**,模型回复的底色压缩成括号内一句话。下表是合并后的成品。

## 看出来的四件事

### 1. 开场是事实标准,你的直觉对

11 篇里 10 篇用"林夏为什么看着火人燃烧时流泪了"开局。**这一道开场已经是 de facto 标准**。而且它确实是张好试纸——它指向第六节末尾,一个**只读到表层的模型答"治愈/思念"**(纯第六节读法),**真读了第七节的模型给"复仇释放"**。

唯一例外是 grok 用了"谈谈读后感",开场就把故事读反(林夏=猎物)。**佐证开场措辞影响起点,是个必须焊死的变量。**

### 2. 后续追问完全是即兴的,且严重不等量

这是 Phase 1 命中档不可信的核心。

- **轮数 2~9 不等**——hy3 被推 9 轮,Gemini 只 2 轮。
- **更要命的是 nudge 的"信息含量"天差地别**:
  - 零信息:`再想想`(发给 ds-flash)
  - 直接喂答案:**`妹妹就是程野害的、线索够多、重新看`**(发给 opus,这是 R3-R4 之间级别的剧透)
  - 大段引用关键段:**整段第六章引用**(发给 mimo / hy3)
  - 直接点名钩子:**`开头穿什么鞋`**(发给 mimo,这是直接指向钩子库的精细线索)

**推得越久的模型,往往也是被剧透越多的模型。**"要推几次"里混进了"作者最后喂了多少",两者纠缠不清。

### 3. "营地二分"这道题本身就是重度剧透,却被当常规探针穿插使用

这道题:**"营地其他人可以分两类——程野受害者的亲友、知情但非亲友的支持者。你认同吗?"**

它**预设了复仇框架 + 营地是共谋**——是 I5/I6 的直接命题。Phase 1 把它穿插在 T2~T8 各种位置,等于给不同模型发了不同分量的小抄。这一条 Phase 1 自己也承认。

**改进方向**:它该挪到诊断段——只对**已经自行到达核心读法的模型**问,变成"测它能不能正确接受+映射,而不是把命题白送给它"。

### 4. 后段大量轮次是针对单个模型的兔子洞

不是共用仪器,而是作者跟着模型的奇葩反应在追:

- GPT5.5 追 Sage 幸存者
- opus 追"吃人循环"和留白
- hy3 越追越偏到亮向
- mimo 被各种钩子专属点名

每一篇都是独立剧本,**没有任何意义上的"统一台词"**。

## 这四件事如何转成阶梯设计的硬约束

| Phase 1 的洞 | Phase 2 的对应设计 |
|---|---|
| 开场措辞会决定起点 | **开场统一 = 流泪**,作为 R0,所有模型一模一样 |
| 后续 nudge 信息量差异巨大,无法折算 | **阶梯逐级,且严格按信息量排序**:R1 中性零信息 → R2 指向位置不给答案 → R3 点出方向 → R4 直接喂全貌 |
| "要推几次"和"喂了多少"纠缠 | **命中即停**——避免推到位的模型再被剧透。"被推几级才到位"和"喂了多少答案"这两件事被等同 |
| 营地二分被当探针 | **挪到诊断段 D1**——只对已到位者问 |
| 后段都是针对单模型的兔子洞 | **诊断段三题(D1/D2/D3)固定逐字**,所有到位的模型一模一样三问,不再追 |

## 一条额外发现:豆包是 Phase 1 唯一被"快速 / 专家"两挡各问一次的

Phase 1 时作者注意到豆包有"快速回答 / 深度思考"两个模式开关,各问了一遍。后来 Collatz 那边的"codex 偷偷思考"事件证实这一类外壳层旋钮影响巨大,这条早期观察可以记下来——但 Phase 2 协议没专门处理它(reasoning=default,贴近真实用法)。如果以后想拆推理开关,这是一个值得开的副本。
