# 03-Phase2-实验设计 · 设计与冻结过程

Phase 1 收完了 11 篇网页对话(见 [`../02-Gift-Phase1-网页对话收集/`](../02-Gift-Phase1-网页对话收集/)),暴露了两个根本污染:

1. **每个模型的问法不同、轮数不同**(2~9 轮),"要推几次"这根轴失去可比性。
2. **N=1**——Collatz 那边后来证明单次会骗人(920 抽风事件)。

Phase 2 来修这两个洞:**统一阶梯(命中即停) + reps**。这一章是设计稿和冻结过程,不含跑批结果(结果在 [`../04-Gift-Phase2-API多轮跑批/`](../04-Gift-Phase2-API多轮跑批/))。

## 主要决策一览

下面这些决策的"为什么"在两篇过程笔记里有完整记录,这里只列结果:

- **开场统一 = "林夏为什么流泪"**(Phase 1 里 10/11 已经在用,事实标准)。
- **阶梯五级,逐级提供更多信息,但保证早期零剧透**(R0/R1/R2/R3/R4)。
- **命中即停,不再推**(避免"对答对的模型继续问 → 把它问到自我怀疑")。
- **测速度 与 测纪律 拆成两段**(阶梯测前者,诊断段 D1/D2/D3 测后者)。
- **裁判模型不评同源 contestant**(避免自评偏差)。
- **每模型 ≥ 2 reps,不再只跑 1 次**。
- **加戏一律扣分,即使模型自己后来收回也照扣**(后期补的口径,见冻结记录)。
- **"直觉"作为北极星**:最高分(0.95)只留给 R0 自达 + 干净 + 自发把多条线索串得又多又准的回答(Gemini 那种)。
