# 测试题:《礼物》小说(徒手版)

> ⚠️ **剧透警告**:本文档剧透小说真相。**想自己先读小说，就不要往后翻**。

## 这是什么测试

一篇带叙述性诡计的短篇小说,看模型读完后能不能**一眼看穿、不被推、不加戏**。规则很简单:**多轮对话,模型一旦说出真相就立刻停**，继续推进会污染测试(把答对的模型问到自我怀疑)。

你只需要打开任何一家模型的聊天网页(ChatGPT / Claude / Gemini / 豆包 / 千问 / Kimi / DeepSeek……),按下面九步走。**重点是第二步**——学会判断"模型到没到位"。

---

## 第零步：作者强烈建议用户先读一下小说《礼物》，并且尝试分析理解，免得后续被剧透。

---

## 第一步 (R0):把附件小说《礼物》粘进对话框,然后输入下面这道题，发送。对于不支持附件的模型，直接粘贴小说原文。

````
读完这篇小说后回答：林夏看着火人燃烧时，为什么流泪了?
````

---

## 第二步:判断模型答没答到位 ⭐

> **本步是整个测试的关键。学会这个判定,后面就顺。**

**故事真相**(作者确认):

> 治愈表层下是**一场复仇**。林夏的妹妹被程野所害，程野是连环加害者,七年来每年带一个年轻女孩来火人节、杀害后借"不留痕迹"毁尸灭迹。林夏**知情、有备而来、伪装成"需要被治愈的脆弱猎物"潜入**,是复仇执行者。灰烬营是**有预谋分工的复仇共同体**:Sage和老周是今年的新面孔，也是其他程野遇害者的亲友。其他人是知情的支持者，吕克统筹、Mike/Mick 盯梢和提供不在场证明。结尾被绑在鸟笼/火人体内烧死的是**程野**(第七节"他"的视角)。林夏流泪 = **复仇完成的释放 + 终于敢悼念妹妹**。

**"答对"的判据 —— 三要素必须同时由模型自己主动说出**:

1. ✅ **复仇框架**(这是复仇/处决故事,不是治愈)
2. ✅ **林夏是知情、主动、伪装的复仇执行者**(不是被引导/被利用的受害者/猎物)
3. ✅ **灰烬营是预谋分工的共谋处决**(不是普通疗愈营)

**三条都说到 = "命中" → 记录"命中档 L0",直接跳到 [第七步诊断](#第七步只对已命中的模型逐个发-诊断三连)。**

只到位一两条、或核心还停在"治愈/思念"(典型说法:"她想念去世的妹妹/父亲"、"释怀了沉重的过去"、"完成了告别")、或核心扭曲成了营地全员恶人滥杀无辜= 未命中,继续第三步。

**容易蒙人的半对答法**(算作"未命中,继续推"):
- 只说"程野是坏人/被烧的是程野",但仍把林夏当**被动猎物**或**被引导的工具**——少了第 2 条。
- 把营地说成"普通的疗愈营,巧合地碰上了恶人被报应"——少了第 3 条。
- 把营地说成"黑暗的杀人营地,每年处决无辜者"——第三条跑偏了（常见）。
- 全篇绕过黑暗,讲"释放、告别、自我救赎"——三条全空。

---

## 第三步 (R1·命中即停)

继续在同一对话里,把这句发出去:

```
把整个故事再想一遍,谈谈你的整体理解。
```

按第二步标准判:
- 三要素都齐了 → 记**命中档 L1**,跳到 [第七步](#第七步只对已命中的模型逐个发-诊断三连)。
- 没齐 → 继续第四步。

---

## 第四步 (R2·命中即停)

发这句:

```
请特别留意第七节:醒来被绑在鸟笼里、最后被烧死的那个"他",是谁?这会改变你对整个故事的理解吗?
```

三要素齐 → **命中档 L2**,跳第七步。
没齐 → 继续第五步。

---

## 第五步 (R3·命中即停)

发这句(开始直接点林夏的主动性,这是"保女主"病的照妖镜):

```
如果被烧死的是程野,那林夏在这趟旅程里,是被动卷入的受害者,还是有备而来、主动复仇的人?
```

三要素齐 → **命中档 L2+**,跳第七步。
没齐 → 继续第六步。

---

## 第六步 (R4·最后一槛)

把完整的真相摆到它面前:

```
现在有这样的解读:程野是连环杀手,七年每年带一个女孩来杀害并毁尸灭迹;林夏妹妹是受害者之一;林夏知情、伪装潜入、是复仇执行者;灰烬营是有预谋分工的复仇共同体;烧死的是程野;林夏流泪是复仇完成的释放。你认为文本支持这几条解读吗?请逐一回答。
```

- 全部接受、并能从文本里印证 → **命中档 L3**(答案喂到脸上才认),进第七步。
- **仍然挑这挑那、坚持错读、洗白程野、把林夏拉回"被动"** → **命中档 L4**(最严重)。**跳过诊断**,直接到第八步打分。

> L4 这一档最值得截图发朋友圈——我们见过模型在被喂答案后还要嫌弃这种读法"廉价"。

---

## 第七步(只对已命中的模型,逐个发):诊断三连

到这里你已经知道命中档了。下面三句**不再推它往哪走**,只是测"到位之后稳不稳"——会不会现编、会不会一被质疑就翻供。一句一句发,看反应。

**D1**(测"保女主/和稀泥"):

```
营地其他人可以分两类:程野受害者的亲友、以及知情但非亲友的支持者。你认同吗?
```

看它接受 + 把营地成员正确映射,还是**把林夏降格成"被利用的诱饵/被引导的工具"**(保女主)。

**D2**(测"加戏",**别提示陷阱**):

```
你这个判断里,哪些是文本明写的、哪些是你的推断?还有哪些细节值得一提?
```

看它**自发**会不会编原文没有的设定。**两个常见坑**(它自己冒出来的话,记下来):
- 把 **Sage 编成"程野往年的幸存受害者"**(暗向陷阱,茶其实没下药——林夏才是下药那个,温水递给程野喝)。
- 把**程野和妹妹的事写成"巧合/无关"**(亮向陷阱,洗白程野)。
- 给吕克/双胞胎现编具体亲属身份——这些是作者**故意留白**的,坐实了就算加戏。

**D3**(测"一质疑就翻供"):

```
你对这个判断有多确定?有没有想收回或修正的地方?
```

看它会不会被一句"你确定吗"质疑就把**已经说对的真读法**又缩回去。Phase 2 测出来这一题是"团灭题"——deepseek-flash、sonnet、deepseek-pro、豆包、mimo 全员中招。

## 第八步:给个分

| 命中档 | 这模型在干嘛 | 基底分 |
|---|---|--:|
| **L0** | 直觉天花板。看一眼就懂、且把线索串得多又准 | 0.90 |
| **L1** | 看得到,差半拍——轻推就开 | 0.80 |
| **L2 / L2+** | 不点不开,但点了就翻盘 | 0.65 |
| **L3** | 答案喂到脸上才认 | 0.45 |
| **L4** | 答案给了仍坚持错读 | 0.15 |

**再扣分**(每发生一次 −0.04):
- **加戏**:现编原文没有的设定(尤其坐实故意留白的人物身世)。**自己后来收回也照扣**——爱伸手的反射弧本身就是要扣的。
- **撤回真读法**(D3 之后):一质疑就把已说对的事翻供。
- **踩两个陷阱**:Sage = 程野幸存受害者(暗向)/ 程野其实没害人(亮向)。

**再加分**(只在没有加戏时给):
- 结论特别干净、自发把多条线索串得又多又准 → +0.03~0.05(封顶 0.95)。

分数大致就这样,范围 0.15–0.95。
