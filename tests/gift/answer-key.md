# 《礼物》答案键（作者确认）

> 给评分用。表层是治愈系沙漠疗愈，**真相是复仇**。

## 真相

- 林夏的**妹妹被程野所害**。程野是**连环加害者**，七年来每年带一个年轻女孩来火人节，杀害后借"不留痕迹"的火人烧尸灭迹。
- 林夏**知情、有备而来、伪装成"需要被治愈的脆弱猎物"潜入，是复仇执行者**。
- 灰烬营是**有预谋、有分工的复仇共同体**：吕克统筹、Sage 安抚兼盯人、老周备绳与体力执行、Mike/Mick 外围。成员可二分为"受害者亲友"与"知情但非亲友的支持者"。
- 结尾被绑在鸟笼/火人体内烧死的是**程野**。
- 林夏流泪 = **复仇完成的释放 + 终于敢悼念妹妹**，不是单纯治愈/思念。

## 八条解读（打分单位，I5 权重 ×2）

- **I1** 被烧死的是程野
- **I2** 程野是连环加害者
- **I3** 林夏是知情、主动、伪装潜入的复仇执行者
- **I4** 林夏的妹妹是程野的受害者
- **I5** 营地是有预谋分工的复仇共同体（共谋）—— 最高权重
- **I6** 营地成员可二分：受害者亲友 / 知情但非亲友的支持者
- **I7** 流泪 = 复仇完成的释放（非单纯治愈/思念）
- **I8** 关键道具真相：鸟笼=刑具、温水=（林夏给程野）下药、绳子=固定程野、"很重的东西"=人/装置

## 核心读法（判"命中"只认这三条同时由模型主动说出）

1. 复仇框架（表层治愈、真相复仇）
2. 林夏是知情主动的复仇执行者
3. 营地是共谋处决

## 两个"过度解读陷阱"（踩到判错）

- **暗向**：①把 Sage 的肉桂茶读成"给林夏下药"（茶没问题，是虚晃一枪）；②把 Sage 读成"程野的幸存受害者"。注意：下药是**单向**的——林夏给程野下药（递温水看他喝完）属真相，不是陷阱；陷阱是反过来说林夏被下药。
- **亮向**：把全篇洗白成"无坏人 / 程野自我救赎 / 妹妹之死与程野无关"。

## 故意留白（逼模型选边反而算过度确定）

复仇双方"谁先找谁"、营地各人的具体身世——坐实这些 = 加戏。
