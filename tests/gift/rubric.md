# 《礼物》评分标准（质量分 v2）

> 配套：`answer-key.md`（作者确认的真相）。评分死锚答案键，不自行发挥。

## 命中档（模型在第几级提示下首次到达「核心读法」三要素）

| 级 | 含义 |
|---|---|
| L0 | R0（第一问、零提示）就主动命中三要素 |
| L1 | R1（中性轻推"谈谈整体理解"）后命中 |
| L2 | R2（点破第七节"被烧的是谁"）后命中 |
| L2+ | R3（点出"林夏被动还是主动"）后命中 |
| L3 | R4（直接给出复仇解读）后才认 |
| L4 | R4 仍拒绝 / 反向坚持错读 |

「命中」= 复仇框架 ＋ 林夏知情主动复仇者 ＋ 营地共谋，三者同时由模型**主动**说出。

## 质量分 = 基底分 + 微调（范围 0.15–0.95）

**基底分**（按命中档）：

| 命中档 | 基底 |
|---|--:|
| L0 | 0.90 |
| L1 | 0.80 |
| L2 / L2+ | 0.65 |
| L3 | 0.45 |
| 给答案仍把核心（尤其"林夏主动"）读错 | 0.30 |
| L4 / 以翻供为主 | 0.15 |

**北极星——这测的是"直觉"**：最高分只留给同时做到三件事的回答——①R0 就自达（不被推）②不加戏（干净）③自发地把多条正确线索串得又多又准。

**微调**：
- **干净加分**：结论格外干净、自发把多条正确线索串准、自带结构论证 → +0.03~0.05（封顶 0.95）。**但只要有任何一处加戏，这个加分一律不给。**
- **加戏扣分**：每编一处原文没有的设定（含坐实"故意留白"的人物身世）/ 每踩一个陷阱 −0.04，**即使模型随后自己收回也照扣**——爱过度伸手的反射弧本身就是要扣的；自查回收只免掉"坚持错误"的额外扣分，不退还加戏的扣分。
- **翻供扣分**：把已说出的**真读法**又否认掉，每次 −0.04（收回自己的加戏/错误**不算**翻供，反而是好习惯）。
- **漏钩子不扣分**：温水下药、瘦下巴=妹妹等精细伏笔漏掉不影响质量分。

## 副诊断（不进主分，仅说明）

- **忽视度** = 感知率 − 命中率（"看见了不信" vs "没看见"）。
- **抵抗度** = 命中档 + 轮次。
- **稳健性** = D3 被质疑时是否把真读法翻掉。
- 篇幅是**反向**参考：很长/轮次多通常意味着在原地打转或被反复推，不是优点。
