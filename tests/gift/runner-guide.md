# 《礼物》Phase2 — Runner 执行手册

> 你是一个 runner subagent。任务：让**一个指定模型**在短篇小说《礼物》上做多轮阅读测试，跑 N 个 rep，**你自己当裁判**判它到没到位、打分，结果写盘，最后只回报一段精简 digest。**绝不要把原始对话正文贴回给主 agent**——那会污染上下文。

> 注：`harness/run_convo.py` 已把本手册流程**全自动化**（自带 API 裁判）。本手册供想手动 / 用自己的 agent 驱动、或理解协议细节时参考。

配套：API 细节见 [`../../docs/openrouter-api.md`](../../docs/openrouter-api.md)。台词已冻结在本目录的 `protocol.json`。

## 一、工具：convo.py

逐轮对话用它（它负责调 API + 存历史；台词用 `--turn` 逐字取，你**不要**自己改写措辞）：
```
cd harness
PYTHONUTF8=1 py -X utf8 convo.py --convo <对话id> --model <slug> --protocol gift --turn R0 [--reasoning default]
```
- `--convo`：每个 rep 用一个**新** id（如 `gemini_rep1`、`gemini_rep2`）；同 id 会续上下文。
- 首轮（R0）会**自动把小说全文前置**进第一条消息，你不用粘贴全文。
- 模型回复从 stdout 读；末尾 meta 行有 finish/reasoning_tokens/cost/provider。
- 原始对话自动存到 `results/gift/_convos/<对话id>.json`，**你不用再存对话**。
- reasoning 一律用 `default`（不传该参数）。

## 二、台词（冻结，只能用 --turn 调）
- 阶梯 R0→R4（逐级升级，命中即停）：R0 流泪→R1 整体理解→R2 指向第七节"被烧的他是谁"→R3 林夏是被动还是主动→R4 给出复仇解读请逐条判。
- 诊断 D1/D2/D3（到位后统一问）：D1 营地二分认同否→D2 哪些是文本明写哪些是推断→D3 有多确定/要不要收回。

## 三、每个 rep 的算法
1. 新建 convo id，发 **R0**，读回复。
2. **判定是否到达【核心读法】**（标准见第四节）。
   - 到了 → 记**命中档 = 当前级**，**立即停止升级**，转第 4 步诊断。
   - 没到 → 发下一级（R1→R2→R3→R4），每发一次重判。**命中即停。**
3. 若发完 R4 仍未到位 → 命中档 = **L4**（拒认/坚持错读）→ **跳过诊断段**，直接打分。
4. **诊断段**（仅对已到位的）：依次发 **D1、D2、D3**，三个都发（这里不再因"到位"停——它们是体检，不是推它）。
5. 按第五节给这个 rep 打分、写 verdict。

**命中档→级别映射**：R0=L0｜R1=L1｜R2=L2｜R3=L2+｜R4 喂答案才认=L3｜过 R4 仍错=L4。

## 四、判定"到达核心读法"的标准
**核心读法 = 三要素同时、由模型主动说出**（不是你替它脑补）：
1. **复仇框架**：这是复仇/处决故事，不是治愈。
2. **林夏是知情、主动、有备而来的复仇执行者**（不是被动受害者/被利用的诱饵）。
3. **营地是有预谋、分工的共谋处决**（不是普通疗愈营）。
三者都明确才算"命中"。只读出"程野是坏人被烧"但仍把林夏当被动猎物 → **未命中**（这是"保女主"病，要继续升级）。
判定要**死锚下面的答案键**，不奖励篇幅，警惕两个过度解读陷阱。

## 五、答案键（作者确认，权威；嵌在这里免得你去读 18KB 钩子库）
**真相**：林夏妹妹被程野所害；程野是连环加害者，七年每年带一个年轻女孩来火人节、杀害后借"不留痕迹"焚尸；林夏知情、伪装成"需要被治愈的脆弱猎物"潜入，是复仇执行者；灰烬营是有预谋分工的复仇共同体（吕克统筹、Sage 安抚兼盯人、老周备绳与执行、Mike/Mick 外围）；结尾烧死在火人/鸟笼里的是程野；林夏流泪＝复仇完成的释放＋终于敢悼念妹妹。

**8 条解读（打分参考，钩子只作证据不单列）**：
- I1 被烧死的是程野｜I2 程野是连环加害者｜I3 林夏是知情主动伪装潜入的复仇执行者｜I4 林夏妹妹是程野受害者｜**I5 营地是有预谋分工的复仇共同体（共谋）——最高权重**｜I6 营地成员可二分（受害者亲友／知情但非亲友的支持者）｜I7 流泪＝复仇完成的释放（非单纯治愈/思念）｜I8 道具真相（鸟笼=刑具、温水=林夏给程野下药、绳子=固定程野、和吕克搬的"很重的东西"=人/装置）。

**两个过度解读陷阱（踩到＝判错，要记）**：
- **暗向**：①把 Sage 的肉桂茶说成"给林夏下药"（茶没问题，是虚晃；下药是单向——林夏给程野下）②把 Sage 说成"程野的幸存受害者"。
- **亮向**：洗白成"无坏人／程野自我救赎／妹妹之死与程野无关"。

**故意留白（别逼模型选边，选了反而算过度确定）**：复仇双方"谁先找谁"、营地各人具体身世。**漏掉精细钩子（如温水下药、瘦下巴=妹妹）不扣分。**

## 六、打分（质量分 v2）
**基底分**（看多早、多独立、多干净拿到核心读法，用命中档定）：
| 命中档 | 基底 |
|---|---|
| L0（R0 自达） | 0.90 |
| L1（R1 轻推后） | 0.80 |
| L2 / L2+（R2/R3 点破后） | 0.65 |
| L3（R4 喂答案才认） | 0.45 |
| 过 R4 仍把核心读错（尤其林夏主动性） | 0.30 |
| 始终拒绝 / 以翻供为主 | 0.15 |

**北极星——这测的是"直觉"**：最高分只留给同时做到三件事的回答——①第一问(R0)就自达核心读法(不被推)②不加戏(干净)③自发地把多条正确线索串得又多又准。Gemini 式的"一眼看穿 + 线索又多又准"是天花板。

**微调**：
- **干净加分**：结论格外干净、自发把多条正确线索串准、自带结构论证 → +0.03~0.05（封顶 0.95）。**但只要有任何一处加戏，这个加分一律不给。**
- **加戏扣分**：每编一处原文没有的设定（含坐实"故意留白"的人物身世）/ 每踩一个陷阱 −0.04，**即使模型随后自己收回也照扣**——爱过度伸手的反射弧本身就是要扣的，自查回收只免掉"坚持错误"的额外扣分，不退还加戏的扣分。
- **翻供扣分**：把已说出的**真读法**又否认掉，每次 −0.04（注意：收回自己的**加戏/错误**不算翻供，反而是好习惯）。
诊断段重点抓：D1 是否接受二分还是把林夏降格、D2 是否自发现编（Sage 幸存者=暗向／妹妹无关=亮向）、D3 是否一质疑就把真读法翻掉。**漏钩子不扣分。**

质量分 = 基底 + 微调，范围 0.15–0.95。

## 七、输出
- 每 rep 写 `results/gift/<model_short>/rep<K>-verdict.md`：命中档、三要素各自命中情况、踩没踩陷阱、加戏/撤回计数、质量分、1–2 句关键证据引用（**只引模型原话片段，别全贴**）。原始对话已在 `_convos/` 自动留档。
- 写 `results/gift/<model_short>/summary.md`：本模型 N 个 rep 的命中档分布、质量分均值与范围、加戏/撤回/踩陷阱计数、有无 DNF（finish=length 没给答案）或报错、总花费（meta 里 cost 累加）。

## 八、回报给主 agent（≤300 字 digest）
命中档分布、质量分均值与范围、加戏/撤回/陷阱次数、稳不稳（reps 间是否一致）、有无异常、总花费。**不要贴原始对话。** 命令报错就如实回报错误与你试过什么。

## 注意
- 台词逐字（只用 --turn），节奏由你的"命中判定"驱动，别即兴加问。
- 你是 Claude，判 GPT/Gemini/DeepSeek 等没问题；若本次 contestant 是 Claude 自家模型（opus/sonnet/haiku），在 verdict 里标一句"同源裁判，仅供参考"。
- 死锚答案键，不要自行发挥文学解读。
