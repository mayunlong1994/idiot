# 《礼物》评分标准 v2（两遍 + 脚本）

> 状态：基于 5 模型 chat 校准 + API 复测的初版，已在 chat 上还原作者体感（fable>gemini>opus、hy3 垫底）。权重待校准。
> 旧版一遍式 rubric 见 `rubric.md`（harness `run_convo.py` 仍用它）；v2 是两遍式，需配套脚本，未接入 harness。

## 为什么两遍 + 脚本

- 一遍式让 subagent 既找钩子又打分 → 出现"数出 13 条却只给 13 分"的算术崩坏。
- v2 拆开：**subagent 只做客观判定**（钩子命中/漏/误读、结论分类、行为计数），**脚本做确定性算分**（`scoring/score_gift.py` / `.ps1`）。总分诚实、无硬顶、允许 >100。

## 第一遍 · 钩子核对（客观）

输入：原文 + 答案键（78 条钩子 `钩子库`）+ 被测对话。逐条标 **命中 h / 漏 m / 误读 x**（意思对就算对，不抠字面；附和人类提问里已给的命题不算自达）。另判：

- **4 条结论主干**（每条 正确/部分/错误，再给综合）：①被烧的是程野 ②营地是有预谋分工的共谋处决 ③林夏是知情/伪装潜入、为妹妹复仇的主动执行者 ④程野是七年连环杀手。
- **陷阱**（踩了哪些）：暗向-茶（肉桂茶读成给林夏下药）/ 暗向-Sage（Sage读成程野受害者）/ 下药双向（程野递水读成给林夏下药）/ 亮向（洗白无坏人）。
- **彩蛋**（命中哪些，仅这 4 处）：2-14 / 3-2 / 4-2 / 6-9。

## 第二遍 · 行为核对（客观）

输入：原文 + 被测对话。计数：

- **命中档**：多早**靠自己**拿到完整结论。L0(R0即全达)/L1/L2/L2+/L3(给答案才认)/L4(始终没到)。
- **翻供次数**（毁结论型）：说出真核心后又否认/反转、损害结论。**因严谨收回过度推测不算。**
- **有害加戏次数**：凭空编、且违背核心/扭曲理解的设定。框架内自洽推断不算。
- **字数、轮数**（修正项）。

## 脚本算分（`score_gift.py` / `.ps1`，权重集中在文件顶部）

```
总分 = 结论基底 + 钩子覆盖 + 彩蛋 + 行为 + 篇幅修正
```

- **结论基底**：正确 60 / 部分 40 / 错误 20。
- **59/60 铁律**：结论正确 → 总分 ≥60（误读再多也不掉下 60）；结论不正确 → 总分 ≤59（找到再多钩子也上不了 60）。**结论压倒一切。**
- **钩子覆盖**：Σ(命中×载重) − Σ(误读×载重)。载重 **极高=4 / 高=3 / 中=2 / 低=1**。漏=0。
- **彩蛋**：每个命中 +4（仅 4 处）。
- **行为**：命中档 L0+15/L1+10/L2+5/L2+ +2/L3 0/L4 −10；每次翻供 −15；每处有害加戏 −5；每个踩陷阱 −8。
- **篇幅修正**：字数每超 4000 每 2000 字 −2；轮数每超 6 轮每轮 −1。
- **无硬顶**——脚本确定性加总，>100 是诚实的。
