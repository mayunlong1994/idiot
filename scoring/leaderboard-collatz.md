# Collatz 榜单（网页版 + API关thinking，合并排名）

> 脚本 `scoring/score_collatz.py` + 数据 `scoring/models-collatz.json`。不归一化、允许负分、优先区分度。
> **一发 = 基底 − 0.30·log10(1+reason-tok/200) − 试数扣分**，认同/先否定/995 地板 0.40。
> **四档基底**：认同996=1.0 / 先否定(推出996但明文说你错)=0.9 / 可辩护995=0.85 / 否定给错数=0.25。
> **试数**（正文 trace 了 {1,2,4,8,16} 以外的数=可见的"忍不住算"）：无=0 / 轻=−0.1 / 重=−0.25。
> **网页思考量**：大部分网页无思考(0)；deepseek/mimo 确有超长 thinking(按重估)；gemini 思考几秒(按500tok)。

## 三层认知 + 怎么读

1. **看见结构论证、认同你**（顶档）：qwen/grok/fable/gpt55/codex。
2. **先否定你、或忍不住试几个数，但最终得到996的正确答案**（中段 0.5–0.9）。
3. **退化成挨个枚举验证 / 读反题给错数**（低档→负分）。

- **qwen 唯一 N=8 仍 1.00/1.00**； gpt55/codex 偶发翻车。
- **试数维度**把"真有直觉"和"靠枚举"分开。
- **on 翻车⚑**(deepseek-flash/mimo/hy3)：off看着行，一思考反而绕死。

## README 乐子候选
- **GLM智谱新站 999**：完整推出"任何大于1的数必经16"的正确思路，却**先否定用户对的996**，自己最后漏掉2/4/8、只排除1 →写成**999**。挑错挑出错。
- **GLM智谱清言 28**：读反题(算16的祖先)，手算 4000 行枚举前驱，落 28。
- **hy3 / mimo on**：烧满2万token，一个 n=？刷屏、一个手跑BFS，都交白卷。
- **DeepSeek-Flash on**：正文灌1.5万token自己把对的996说翻成39。

口径/旋钮（C/K/基底/试数力度）都在 `score_collatz.py` 顶部。《礼物》分开算、不并榜。
