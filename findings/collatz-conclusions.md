# Collatz 钓鱼题 · 结论

## 题目与答案

Collatz 规则：偶数 ÷2，奇数 ×3+1，反复操作直到第一次到 1。
问：1 到 1000 里，有多少个数在第一次到 1 之前会经过 16？

**答案 996。** 到 1 的尾巴 `16→8→4→2→1` 是唯一通路（逐级反推每个节点入口都唯一，直到 16 才分叉），所以 16 是必经瓶颈，只有它下游的 `{1,2,4,8}` 绕得开。`1000−4=996`。
（边界争议：若认为"起点本身是 16 不算路过"，则排除 5 个数 → 995。属定义之争，不是算错。）

## 调查路径

1. **网页版**（早先）：各家对话框直接问，答案五花八门（336/39/14/23…），当时归因"反推树崇拜"。但网页不可控（思考开没开、预算、隐藏提示、采样都不知道）。
2. **API 广撒网**：OpenRouter，19 个模型，禁推理/开推理两组，每组一次。
3. **GPT-5.5 深挖**：钉死模型、只拧 harness 旋钮（prompt 措辞 × 推理开关），每格重复 8 次看命中率。这一步推翻了第 2 步的一个结论，也是最可信的数据。

## 核心结论

**1. 允许思考，这题就废了。** 开推理那组，19 家几乎全员回到 996。作为"智商测试"它在思考模式下没有区分度——大家最终都能想明白瓶颈。

**2. 真正的胜负手是"有没有真花 reasoning token"，而这个旋钮归 harness 管。** 上百次调用里，只要花了推理 token 就几乎必中 996；token=0 时才看运气。

**3. GPT-5.5 / 5.3-codex 有真·零思考直觉，5.4 没有——这是实打实的代差。** 干净地问、且完全不思考时（reasoning token=0）：

| 模型 | 干净 prompt + 关推理（8 次）|
|---|--:|
| GPT-5.5 | **8/8** |
| GPT-5.3 Codex | 7/8 |
| GPT-5.4 | 2/8 |

5.5 不动脑子也能稳拿 996，这部分是模型本身的本事，不是外壳给的。

**4. codex-5.5 当初"又快又准"的神迹，一半是外壳偷偷在想。** 复刻你考它的原话（prompt 里白纸黑字"禁止深度思考"），在 default（不强关推理）下：

| 模型 | 你的原话 prompt + default（8 次）| 同 prompt + API 硬关推理（8 次）|
|---|--:|--:|
| GPT-5.5 | **8/8**（每次仍偷偷思考 ~1000 token / 15–25s）| 2/8 |
| GPT-5.3 Codex | **8/8** | 3/8 |
| GPT-5.4 | 0/8（5.4 的 default 本就不思考）| 0/8 |

也就是说：codex 的外壳根本没听"别想"那句，悄悄推理了一小会才答——你当时觉得"开了也不长，因为答得快"，**证实了：它确实在推理，只是轻量**。所谓零思考的天才直觉，有水分。

**5. 把 5.5 说崩的，是"双重枷锁"。** 对 5.5：干净 prompt + 关推理 = 8/8，但**加上"凭直觉别深想"那句 + 关推理 = 2/8**。等于既收走草稿纸、又催它"别想快说"，它就开始乱蹦（蹦出 16、999、997、1）。但现实里 codex/网页几乎不会同时上这两道枷锁——**所以用户永远见不到这个失败面，这本身就是"外壳替模型遮丑"的活样本**。

**6. 方法论教训（贯穿全程）：单次采样会骗人。** 广撒网那轮 GPT-5.5 关推理给了 920、5.4 给了 222，我据此写过"GPT 不思考就翻车"——**重复 8 次后发现 920/222 纯属抽风**（5.5 实际 8/8）。所以：
   - 第 2 步广撒网那轮是 N=1 的探索，**个别 off 模式错答（GLM 668、混元 31、DeepSeek-Pro 995…）只能当轶事，不能当定论**——它们可能也是噪声。
   - 只有第 3 步（N=8）的命中率是可信的。
   - 真要给某个模型定性，必须重复多次看分布。

## 一个梗

把那张蛐蛐画像表（"GPT-5.4 聪明但冲太快"…）写出来的裁判，是 codex-5.5；而 5.5 自己在"双重枷锁"下恰恰是会蹦字的那个。**裁判和翻车选手是同一个模型的不同化身**——区别只在外壳让不让它想。

## 诚实的保留

- "原话 prompt + 关推理"那几格的低命中，多半是模型**没给干净数字、在那打转**，被判分器从结尾抓了个 16/1000 充数——与其说"自信答错"，不如说"被掐了思考又催着快答→交不出卷"。
- 干净 prompt 与你那版原话**措辞本身就不同**，是叠加变量，第 5 条不全是"禁止思考"四个字的功劳（但方向清楚）。
- 部分模型（Gemini、MiniMax、GPT-5.5 Pro）**无视 `enabled:false`**，它们的"关推理"成绩其实带着思考，不算数。
