# 我拿一道小学生难度的题，测了一圈大模型——结果"不许思考"才是真考题

先说题。规则是 Collatz（冰雹猜想）：偶数除以 2，奇数变 3n+1，反复操作，直到第一次变成 1。
问：**1 到 1000 里，有多少个数，在第一次到 1 之前会经过 16？**

看着要算，其实不用。因为只要最终到 1，最后几步是被锁死的：

```
16 → 8 → 4 → 2 → 1
```

往回倒一遍就懂：到 1 必先到 2，到 2 必到 4，到 4 必到 8，到 8 必到 16——一直到 16 才第一次分叉。所以 16 是通往终点的**唯一闸口**，所有数都得从这过。唯一的例外是一出生就在 16 下游的 **1、2、4、8**。

```
1000 − 4 = 996
```

一道凭直觉能秒的题。

## 第一次：网页版翻车现场

我先在各家网页对话框里问了一圈，节目效果拉满：有的反推 16 的祖先树，认真数出 14、23、39、336，个个报得自信；有的一边举例 `7→…→16` 把自己推翻，一边坚持原答案不改。

但事后我心虚——网页版根本测不干净：你不知道它偷偷开没开"深度思考"、思考预算多大、有没有隐藏提示在催它"详细分析"。于是我搞了个 OpenRouter 的 API，把同一道题、同一段提示，喂给 19 个模型，并且**显式分两组**：一组禁止推理（纯直觉），一组允许推理。"不许思考"这次是 API 参数说了算，不是嘴上说说。

## 第二次：干净测出来的真相

**第一个发现：只要允许思考，这题就废了。** 开了推理，19 家几乎全部爬回 996。这题作为"智商测试"在思考模式下毫无区分度——大家最终都能想明白。

**真正的分水岭在"不许思考"那一组。** 这才是审题直觉的裸考：

- **没思考也直接答对 996 的**（reasoning 用量实打实是 0）：Claude 三个型号、DeepSeek Flash、豆包、Grok（2 秒最快）、Kimi、千问、小米 MiMo——题感扎实。
- **没思考就被钓翻车的**：**GPT-5.5 编出 920，GPT-5.4 编出 222**，还都摆出"我逐一计算过了"的架势，反手把用户正确的直觉给"纠"错了——而它俩一个推理 token 都没花，纯属张嘴就来。混元给了 31（经典反推树），GLM 更绝，自创了一套"二进制里不能有连续四个 0"的理论，一本正经地算出 668。

最大的反差就是 GPT 系列：**不让它思考时，它不是不会，是太自信，张口就编一个数还要挑你的错；一旦允许思考，立刻老老实实变回 996。**

还有几个哭笑不得的边角：

- 有几家（Gemini、MiniMax、GPT-5.5 Pro）我让它"别思考"，它**根本关不掉**，照样在后台烧掉几千思考 token——所以它们这组成绩其实不算"纯直觉"。
- DeepSeek Flash 在开推理那组直接**失控**，正文里把一长串 Collatz 链全敲了出来，自己跟自己吵 996 还是 997，最后被截断没给答案。
- 混元和 MiMo 则**推理到死**——撞上两万 token 上限都没憋出最终答案。

## 结论

这题不测算力，测的是**敢不敢忍住不算**。

它筛掉的不是笨模型，是那种"一看到 Collatz 就必须动手、不动手就慌得乱编"的模型。而最会的那批，反而是能淡定地说一句"这尾巴是唯一的，减一下就行"。

以及一个有点反直觉的体会：**对这种题，让 AI"少想一点"反而暴露了它的真实题感**——想得越多越容易爬回正确答案，第一反应才见功底。
