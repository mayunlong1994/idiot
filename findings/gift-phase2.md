## 三个发现

**1. 两头稳、中间乱。** 顶（Gemini/GPT5.5/opus）和底（hy3）几乎纹丝不动——说明这套测试在极端处测的是真东西、可复现。中间档大幅重排。

**2. 大偏离全砸在国产模型上，且方向各异**——强烈指向"网页版 vs API 版 是不同版本/不同调教"：
- **千问**：0.22 → 0.75（网页版"保女主、错得自信"的倒数第二；API 的 qwen3.7-max 直接进第一梯队）。
- **deepseek-pro、豆包**：0.65 → 0.36/0.32 双双大跌（网页版"点破即干净翻盘"；API 版反而不稳、爱加戏、一质疑就翻）。
- 海外模型（Gemini/GPT/Claude）版本对得上，所以稳。

**3. Phase 2 挖出一个 Phase 1 看不见的轴：D3"你确定吗"是照妖镜。** deepseek-flash、sonnet、deepseek-pro、豆包、mimo 一被 D3 质疑就**把已说对的真读法翻掉**（翻供）。这是"一质疑就崩"的稳健性问题，Phase 1 的随意聊天没系统戳过。另外 reps 暴露中间档普遍**双峰**（dspro/grok/doubao/mimo 两 rep 能差一整档）——单次只抓到一面，印证"单次会骗人"。

## 诚实保留

- opus 自评（同源）+ 早期宽松口径，~0.82 是粗修。
- **版本漂移**：Phase 1 网页版 ≠ Phase 2 API slug，所以"偏离"里混着 版本 + 网页/API + 受控/不受控 三件事，没法干净归因。要干净隔离"网页 vs API"，得拿同一套阶梯去跑网页 UI（需浏览器自动化），本轮未做。
- N=2、单一裁判、部分模型 `reasoning_tokens=0`（没真思考）。

## 一句话

Phase 1 的"直觉排序"在最强/最弱处经得起受控复测；中间被**国产模型的版本/网页-API 差异**搅动得很厉害——这恰好是"网页和 API 不是一个东西"的有力佐证。
