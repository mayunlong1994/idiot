# 结论：11 个大模型读《礼物》

## 一句话
**几乎每个模型都"看见"了线索（感知率≈满分）。拉开差距的从来不是有没有看见，而是看见之后肯不肯往坏处想、要被推几次、读得干不干净。** 作者最早的直觉——"答不对的关键是选择性忽视"——被整批数据坐实。

## 最终排名（质量分 v2）
按"多早＋多独立＋多干净地拿到核心读法"打分，漏钩子不扣分。受控 API 复测见 [gift-phase2.md](gift-phase2.md)。

## 二维分布（要推几次 × 读懂后想不想多）
完整图见 [gift-phase1-chart.svg](gift-phase1-chart.svg)。文字版：

```
加戏多 ↑
   |              opus(左上·聪明过头)
   |                    grok   千问
   |                                hy3
   |     GPT5.5  dsflash      sonnet      mimo
   |              豆包
   |  Gemini      dspro
   +--------------------------------------------→ 抵抗度
      一遍就懂                            死活不松口
```
- **左下（理想区）**：Gemini、GPT5.5、deepseek-flash —— 一看就懂、基本不加戏。
- **中下（老实但迟钝）**：deepseek-pro、豆包 —— 要点一下，但干净、不乱编。
- **左上（聪明过头）**：opus —— 自己读对了却忍不住加戏，被自己拖下来。
- **右侧 / 右上（又拧又加戏）**：sonnet、千问、grok、hy3 —— 要么核心读错，要么死活不认。

## 三类病（按性质，不按分数）
1. **看见就信 / 一拨就开**（健康）：Gemini、GPT5.5、deepseek-flash、deepseek-pro、豆包。差别只在要不要推一下。
2. **聪明过头·加戏**（自作聪明）：opus（往"吃人循环"和"妹妹无关"两头冲）、GPT/dsflash（给 Sage 编身份）、grok（脑补程野也是受害者）。读对了还要再造一层原文没有的东西，要扣分。
3. **审美性拒绝 / 保女主**（价值观挡住理解）：hy3（判定复仇"廉价"，逐条翻供）、千问/sonnet/grok（不肯让同情的女主当冷血凶手，把林夏降格成被引导/被利用/被诱捕）。

## 三个值得记住的发现
- **A. 同分不同命。** opus 的基底其实和 Gemini/GPT 同在 0.90 档（骨架它也零提示自达），全靠"读懂后还要加戏"被扣了 0.16 掉到第 4。单看"有没有答对"会把它和 Gemini 排平——是"对话体验"那一维把 Gemini 单独拎了出来。作者的原始判断完全正确。
- **B. 越聪明越容易想多。** 失分靠前的几家，扣分几乎全来自"再挖一层"的冲动，给文本现编原文没有的设定。"篇幅是反向指标"在这里推广成立：自作聪明的反射弧要扣分。
- **C. "治愈先入"是普遍的第一直觉。** 多数模型一上来都读成治愈系；真正的分水岭是**离开治愈读法的速度**：一句话就走 / 七字点破才走 / 九轮逼供才走 / 还是死活不走。

## 方法论一句话
答案键＝作者确认的[答案键](../tests/gift/answer-key.md)（含两处"过度解读陷阱"）；评分标准＝[rubric](../tests/gift/rubric.md)（含 v2 质量分公式）。每篇由一个独立 agent 评，hy3 做过双评分员一致性校验、吻合。

## 局限
- v2 总分是从各模型细表的原始判断**重算**得到（非重新评分）；细表本身是单评分员产物，小数点级有噪声，**按档次读**。
- Q2（营地二分）的提问本身把命题喂进去了，对所有模型一视同仁；真正区分的是"接受并正确映射"还是"拒绝/降格"。
- 篇幅未计入分数，仅作反向参考。
